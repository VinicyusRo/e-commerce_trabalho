# PC Store

E-commerce de peças de PC com prévia 3D de cada produto, feito para as disciplinas de Banco de Dados e Computação Gráfica.

**Site:** [e-commerce-trabalho.vercel.app](https://e-commerce-trabalho.vercel.app)

## Destaques

- **Prévia 3D com Three.js:** cada produto tem um visualizador 3D, com tela cheia. Aceita modelos GLB/GLTF e modelos procedurais gerados por código (CPU, GPU, RAM e SSD), com animação das ventoinhas.
- **API REST em Node.js:** produtos com busca e filtro por categoria, cadastro e login com JWT, endereços e pedidos.
- **PostgreSQL:** schema e dados de exemplo em SQL, view que escolhe o modelo 3D de cada produto e criação de pedidos em transação com FOR UPDATE.
- **Frontend com Vite**, que repassa as chamadas da API para o backend.

## Tecnologias

JavaScript · Vite · Three.js · Node.js · PostgreSQL · JWT · HTML e CSS

## Como rodar

O código está na pasta [ecommerce-pc-main](ecommerce-pc-main). O passo a passo completo (banco, backend e frontend) e a documentação da API estão no [README do projeto](ecommerce-pc-main/README.md).
